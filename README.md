# UPDATED-DCSA — College of Saint Adeline Student Portal

This package is arranged to match the root of your existing `UPDATED-DCSA` GitHub repository. The website files and both image files are all at the same level, so you do not need to move files into an `assets` folder or edit image paths.

## Files
- `index.html` — website and page structure
- `style.css` — responsive styling and school colors
- `script.js` — sign-in prototype, registration, and role-based dashboards
- `dcsa-logo.jpg` — school logo
- `campus-courtyard.jpg` — campus background

## Update your existing GitHub repository
1. Download and extract this ZIP.
2. Open your `UPDATED-DCSA` repository.
3. Upload the five files above to the repository root, replacing the existing files with the same names. Keep the image filenames exactly as shown.
4. Commit the changes. If GitHub Pages is already enabled, wait a minute or two and refresh your site.
